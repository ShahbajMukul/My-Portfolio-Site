Fullstack Applications

Atomio - A STEM Focused Social Media Platform

Atomio is a full-stack web application that I developed using the MERN stack and later added the support for android devices using Android Studio. It is a social media platform that is focused on STEM. It allows users to create posts, like posts, comment on posts, and follow other users. This project was a great learning experience for me as I learned how to work with the MERN stack and how to create a full-stack application. It has an authentication system that allows users to securely log in and log out of the application. The android application is highly responsive and has a user-friendly interface. The support for IOS devices is in the works. The software also has a content moderation system powered by an AI that checks the content of the user's posts before allowing them to post to keep the community safe.


Bright Scholarship System Software

The Bright Scholarship Management System is a comprehensive solution designed to streamline the process of managing scholarship applications, reviews, and awards. Developed using ASP.NET Core Minimal APIs for the backend and Blazor WebAssembly for the frontend, this system ensures efficiency and transparency. Key features include application submission, login, review, authorization, voting, and automated winner selection, all supported by a robust SQL Server database.

Random Forest Classifier To Detect Downtime Reason

This project is a machine learning model that I developed using Python that uses a random forest classifier to detect the reason for downtime in a manufacturing plant. The model is trained on a dataset that contains information about the downtime and the reason for the downtime. The model is designed to predict the reason for downtime based on the information provided. This project was a great learning experience for me as I learned how to work with machine learning models and how to train and test them. The model has been successfully trained and tested and is able to predict the reason for downtime with a relatively good accuracy.
